# Art Homes Interior Studio

> Premium Residential Interiors & Architectural 3D Visualization Studio based in CV Raman Nagar, Bengaluru & Hosur.

**Live Website:** [https://arthomeswebsite.vercel.app/](https://arthomeswebsite.vercel.app/)

---

## 🌟 Highlights & Features

- **Architectural 3D Portfolio:** High-definition 3D renders matching turnkey execution for modular kitchens, living partitions, master bedrooms, and pooja spaces.
- **Hero Video Background (Desktop):** Seamless cross-fading interior showcase video for PC displays with graceful degradation to high-res portrait imagery on mobile.
- **Continuous Carousels:** Infinite right-to-left ticker carousels for verified homeowner reviews and "The Art Homes Difference" features on mobile.
- **Animated Metric Counters:** Dynamic count-up counter (0 to 100+ Turnkey Homes, 10-Year Warranty, 45-Day Handover, 100% 3D Previews) with `easeOutCubic` curve and tabular numerals.
- **Direct WhatsApp & Instant Booking:** One-tap inquiry links, auto-filled WhatsApp message generators, and direct phone dialers.
- **Responsive & Touch Optimized:** Handcrafted responsive design across 4K, Desktop, Tablet, and Mobile screens.

## 🚀 Local Development

1. Clone or download the repository:
   ```bash
   git clone https://github.com/explorewithharizz-rgb/ARTHOMES.git
   cd ARTHOMES
   ```

2. Start a local server:
   ```bash
   # Using Node.js (included server)
   node server.js

   # Or using Python
   python -m http.server 3001
   ```

3. Open `http://localhost:3001` in your browser.
